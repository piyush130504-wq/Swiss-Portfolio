# Piyush Priyadarshi - Swish portfolio

A static, responsive portfolio tailored for a Product Design Intern application. It intentionally describes Piyush as a product-minded engineer and limits project claims to the available resume and live-product context.

## Run locally

No build or package installation is required. From this folder, run:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deploy to Vercel

1. Create a new GitHub repository and upload these files.
2. In Vercel, select **Add New → Project** and import that repository.
3. Keep the framework preset as **Other**. No build command or output directory is needed.
4. Click **Deploy**. Use the generated `https://…vercel.app` address as the Portfolio Link in the Swish form.

Alternatively, drag this folder into Vercel's dashboard to deploy it as a static site.
